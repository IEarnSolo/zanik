# Dragonwilds server update 25501739

## Summary

The development server updated from Steam build `25465077` to `25501739` on September 29, 2026. The official Linux executable changed to SHA-256 `d12145525d88f3828ebeac0aec3865f5b16ba4771861efe65108754a89bbb090` and size `229648384` bytes.

The website initially became unavailable because the permanent bootstrap exported `LD_PRELOAD` to its helper processes. Validation programs such as `curl`, `sed`, and `sleep` consequently loaded the web mod and competed with the game for TCP port `29105`. The resource subsystem also rejected the new executable fingerprint and retried initialization continuously, consuming a CPU core.

## Compatibility changes

- Preserved the exact updated executable and matching symbols for analysis.
- Added build `25501739` to the fingerprint-bound compatibility manifest.
- Relocated and validated the AI kill hook, Unreal object array, name pool, region/map helpers, lodestone and nodestone helpers, and resource functions against the matching executable and symbols.
- Added the new resource function addresses for game time, time provider, respawn interval, foliage identity, depletion, amount changes, and respawn completion.
- Kept the previous build's native values so its compatibility entry remains reproducible.
- Added a five-second retry delay for unavailable resource compatibility, preventing an incompatible future build from creating a tight CPU loop.

## Startup repair

- Scoped `LD_PRELOAD` to the Dragonwilds executable only.
- Added a process-name guard in the mod constructor.
- Changed the analyzer build to use static C++ and GCC runtimes for compatibility with the server container.
- Made the updater preserve the newly downloaded executable and symbol pair before analysis or rollback.

## Preserved data and features

The player database, known players, skills, locations, kill history, resource catalog and state data, web assets, map labels, lodestones, nodestones, and update backups were preserved. No production files were changed.

## Verification

Local compilation and unit tests passed. Development validation reported:

## Production promotion

Production server `ef68362b` was backed up and promoted on September 29, 2026. The first guarded Steam update attempt correctly aborted because SteamCMD could not apply a binary delta to the launcher installed at the official executable path. The updater was amended to restore the preserved game executable before patching and to restore the launcher on failure. The retry completed successfully and passed validation.

Production validation reported 5 preserved known players, 48 lodestones, 18 nodestones, 31 map labels, and 31,910 resource nodes. The database remained 42,288 bytes, the server stabilized at approximately 4% idle CPU, and the website continued serving on port `29103`.

Live player and region validation remains conditional on a player being connected during the check.

## September 30 resource timer correction

The relocated `GetInGameTimeProvider` address belonged to an instance method on `UInGameTimeSubsystem`, while the resource tracker was passing a resource component as the receiver. Production's larger loaded resource set invoked this invalid combination repeatedly, producing 95,101 errors in the final pre-fix log. The tracker now resolves the live subsystem instance before requesting its provider. Development validation passed, the production APIs remained compatible, and the fresh production log held at one early startup warning with no additional occurrences during observation.
