## Storage and gravestone teleport transport

The build moved `ADominionPlayerCharacter::TriggerDelayedTeleport` and changed its prologue. Zanik validates the new 17-byte prologue at module-relative offset `0xA5765A0`, the `BP_TriggerDelayedTeleport` wrapper prefix at `0xA576B80`, and the wrapper's first relative call back to that exact implementation. A persisted native parameter template is structurally validated before replay; when it is already available, Zanik does not install the diagnostic capture hook.

Storage and gravestone destinations are resolved before entering the game-thread queue and bound to the live Unreal object identity when an actor exists. The game-thread path performs one authoritative bounds read, at most one ground trace, and one native delayed-teleport scheduling call. Broad object scans, nearby-building scans, multi-candidate loops, and filesystem diagnostics are excluded from this path. The native call has an independent 1 ms circuit breaker and exposes its maximum and slow-call count through `/api/update-status`. Storage and gravestone teleport fail closed together if this shared transport is unavailable; lodestone and player teleport remain independent.

After production world initialization, every enabled feature reported `compatible`. The root, map, and player pages and all representative map-label, lodestone, nodestone, resource, NPC, recipe, quest, kill, and diagnostic endpoints returned HTTP 200. The existing asset manifest remained compatible. The production shared-dispatcher maximum was 44 microseconds and the NPC scanner maximum slice was 529 microseconds, both with zero slow calls. No asset extraction was required.

Live player transitions, region lookup, recipe and quest capture, and combat registration were not repeated during this maintenance window. The automated results are not replacement evidence for the normal pre-production gameplay and A/B requirements. Those paths must be observed before a later promotion that depends on them, and any regression must trigger rollback or an immediate feature-specific disablement.
