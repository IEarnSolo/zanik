# Authored asset-tool artwork

`nodestone-icon-master.png` is the retained 1254x1254 transparent master for Zanik's top-down Dowdun Reach nodestone map marker. `nodestone-icon-map.png` is its reviewed 256x256 high-quality bicubic derivative and is the only version packaged with the Windows extractor.

These are Zanik-authored static assets. They are not cooked Dragonwilds textures, extracted game assets, or outputs of a runtime model renderer. Regenerate smaller derivatives from the master rather than upscaling the packaged map image.
